Research Platform v5 / Public replication

Nasdaq FVG replication · 2010–2026

A free-source companion to the frozen CME MNQ study. It is designed to test the same FVG hypotheses across a much longer Nasdaq-100 price history without pretending the proxy feed is futures data.

Current status: the infrastructure is complete and cross-platform verified. The full 5,046,180-row, 12-stage NSX/USD replication has not yet been completed and reviewed, so this page intentionally publishes no new NSX/USD conclusion.

The repository can audit and normalize the merged CSV, convert its fixed-EST timestamps correctly, query prepared Parquet with DuckDB, resample to 1m/5m/15m/1H/4H, display local candlesticks with mechanically detected FVG overlays, rerun individual experiments, resume a complete replication, and generate machine-readable summaries and a separate HTML report.

“Live” means local. The 365 MB raw HistData-derived market file is not hosted on this portfolio or committed to Git. After a reader obtains the free source and prepares it locally, the Streamlit Research Lab reads the real observations interactively.

Why it stays separate from MNQ

NSX/USD is a Nasdaq-100 index-style quote feed, not CME NQ or MNQ futures. It is useful for asking whether price-pattern behavior survives more years and market regimes, but it cannot validate futures volume, contract rolls, exchange ticks, slippage or execution.

The preserved CE/body script also inherits an MNQ-specific 0.25-point minimum-gap and width-unit convention. On the public proxy track, those fields must be read as transferred 0.25-point method units—not as NSX/USD exchange ticks.

Research rule: public NSX/USD results may challenge or support the price-pattern hypothesis, but they never overwrite the frozen CME MNQ findings.

Reproduce it

Download the merged free HistData source, then prepare it locally: 

python scripts/prepare_histdata_nsx.py --input "C:\path\to\NSXUSD_M1_ALL.csv" --output data/public/nsxusd

python scripts/reproduce_public_nsx.py

python scripts/generate_public_nsx_report.py

The optional GitHub Release installer exists only for a future data asset if redistribution permission is explicitly confirmed. The repository does not assume third-party redistribution rights.

What comes next

The next evidence milestone is not another UI feature. It is the completed 12-stage run on the full 5.05M-row dataset, followed by review of the audit report and experiment outputs. Only after that should this page show NSX/USD attraction, reaction, age-decay, midpoint, regime or chronological-robustness statistics.

That comparison will then answer the useful question: does the small, short-lived FVG structure seen in MNQ survive a substantially longer Nasdaq-related history?
