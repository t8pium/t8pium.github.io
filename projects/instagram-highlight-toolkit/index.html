Instagram Highlight Toolkit

Why I built it

I wanted a repeatable way to archive and restore my own highlights, with file order preserved and setup handled by a launcher.

Run experience

  • Uses a root-level launcher instead of requiring command prompt setup.
  • Creates the local Python environment, installs dependencies, and exposes the main actions as a menu.
  • Keeps the original Python scripts directly runnable for advanced use.

Backup side

  • Launches or connects to a dedicated Chrome profile.
  • Uses manual login instead of collecting credentials.
  • Uses the currently opened profile page or an entered username or profile URL.
  • Detects highlight links and keeps the workflow local.

Restore side

  • Uses a folder picker to choose an ordered local highlight folder.
  • Calibrates visible buttons on the uploader extension page.
  • Steps through Add, Next, Publish now, and OK.
  • Waits 60 to 70 seconds after OK before the next file.
  • Supports dry runs, start position, and limits for resuming.

Boundary

The tool does not automate login, verification, CAPTCHA, account checks, or security decisions. It depends on the user controlling the browser and using the tool responsibly.
