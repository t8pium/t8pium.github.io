Project / Market simulation + data visualization

Topium Dice Market

A local Python charting experiment where coin flips decide direction, dice rolls decide movement size, and raw one-minute candles aggregate into higher timeframes.

View source on GitHub ↗
Project illustration
Status
Working prototype
Focus
Random engine to chart structure
Stack
Python, Tkinter, Matplotlib

Problem

I wanted a small, understandable market simulator that did not depend on real price feeds. The challenge was to take a very simple random rule and build enough structure around it to make the result feel like a real charting tool.

Build

  • Created a coin-and-dice engine where each raw candle is built from five internal moves.
  • Stored the base market as one-minute OHLC candles.
  • Aggregated those candles into higher timeframes like 5m, 1h, 4h, 1D, and 1W.
  • Built a dark Tkinter interface around a Matplotlib candlestick renderer.
  • Added pan, zoom, reset view, export, VWAP, and three VWAP deviation bands.

What I learned

Even fake markets need structure. Once the chart has timeframes, state, panning, indicator history, and exported candle data, the project starts behaving like a small local analysis tool.

Design thinking

The app is intentionally simple: no accounts, no external APIs, and no real market data. That keeps the logic visible. The point is to show how raw randomness becomes readable only after it is shaped into candles, grouped into timeframes, and compared against reference indicators.

Next version
