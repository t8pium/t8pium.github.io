Methods / Experiment 00

Dataset & methodology

How the MNQ series, FVG events, controls, and statistical safeguards were constructed before any hypothesis was judged.

Dataset

Base observations2,303,483
Contracts used27
Period2020–2026

The source was Databento GLBX.MDP3 one-minute OHLCV for the parent symbol MNQ.FUT. Because a parent-symbol export contains multiple listed expiries at the same timestamp, the contracts could not simply be mixed.

Continuous series

  1. Aggregate total traded volume by listed contract for each CME trading date.
  2. Select the highest-volume outright MNQ contract for that trading date.
  3. Use only that contract's one-minute bars for the active series.
  4. Exclude event/control formation near contract transitions to prevent synthetic roll jumps from creating artificial gaps.

The final active series had no duplicate timestamps and no missing OHLC fields.

FVG definition

For completed candles A=t−2, B=t−1, C=t:

  • Bullish: Low[C] > High[A]; zone High[A] → Low[C].
  • Bearish: High[C] < Low[A]; zone High[C] → Low[A].
  • The event becomes known only after candle C closes. No lookahead is allowed.

Events were characterized by width, ATR-normalized width, distance, ATR-normalized distance, direction, session, time bucket, volatility, trend, displacement, year, and other state variables as required by each experiment.

Matched controls

The main falsification device was a synthetic ordinary price zone placed at another eligible non-FVG timestamp. Controls were matched on the most important observable state variables: direction, gap width, ATR-normalized width, direction relative to current price, ATR-normalized distance, session/time bucket, volatility regime, and trend regime.

Reason: a raw FVG fill rate is not evidence if any nearby price level would be revisited just as often.

Uncertainty

  • Chronological train/test splits were used instead of random shuffling.
  • Day-level bootstrap/clustering was used where practical because events from the same trading day are dependent.
  • Results discovered after scanning many bands/timeframes are labeled exploratory.
  • For execution tests, a one-minute bar that contains both TP and SL is intrabar ambiguous. Those cases were reported separately rather than assigned a favorable sequence.

Exact implementation

1. Raw Databento export

The study starts from a Databento GLBX.MDP3 parent-symbol export for MNQ.FUT using ohlcv-1m. Parent symbology returns multiple listed child instruments at the same timestamp, including calendar spreads, so those rows are not treated as a continuous market directly.

2. Active-contract construction

  1. Keep quarterly MNQ outrights matching ^MNQ[HMUZ]\d$; spread symbols are excluded.
  2. Convert every timestamp to America/New_York. The CME trading date advances at 18:00 ET: bars at or after 18:00 belong to the following trade date.
  3. Sum one-minute volume for each outright over the entire CME trading date.
  4. Select the outright with the largest daily total volume and retain only that symbol's one-minute bars for that trade date.
  5. Do not back-adjust prices. The final study snapshot contains 2,303,483 bars and 27 active contracts.

Series-construction caveat: the highest-volume contract is selected using the completed trading day's total volume, so this is ex-post continuous-series construction rather than a causal intraday roll signal. The main matched experiments exclude observations within ±1 day of a contract transition. Future work can repeat the study with a fully causal predetermined roll calendar.

3. Higher-timeframe bars

For the matched multi-timeframe and midpoint studies, one-minute bars are resampled in New York time using an 18:00 ET origin, left-closed / left-labeled intervals. This matters for 2H/4H boundaries. The CE execution study instead groups by CME trade date plus minutes since the 18:00 session open and refuses to construct a higher-timeframe bar that spans two active symbols.

4. State variables

The multi-timeframe matched studies use 14-native-bar mean true range as ATR, a 20-native-bar ATR-normalized trend measure, and an ATR/rolling-median-ATR volatility ratio. Volatility is bucketed into <0.8, 0.8–1.2, and >1.2. Trend is bucketed at −1, −0.25, +0.25, and +1 ATR. Session labels are Asia, London, NY premarket, NY AM, NY lunch, NY PM, and post-market.

5. Reproducibility gates

The data builder prints row count, contract count, start/end timestamps, duplicate count, and missing OHLC count. The exact study archive SHA-256 is published. Synthetic unit tests separately verify bullish/bearish FVG detection and the rule that a same-bar TP+SL event is ambiguous.

Exact preparation pipeline

  1. Request Databento GLBX.MDP3 ohlcv-1m using parent symbology for MNQ.FUT.
  2. Convert timestamps to UTC and preserve each listed contract symbol.
  3. For each CME trading date, sum one-minute volume by listed expiry and select the highest-volume contract.
  4. Concatenate only those active-contract bars into one research series, remove duplicate timestamps, and retain the listed symbol so contract transitions remain visible.
  5. Mark roll boundaries and exclude FVG/control formation roughly one day around those transitions.
  6. Calculate ATR and market-state variables only from information available at or before the event bar.
  7. Detect FVGs only after candle C closes; no result may use the gap before that close.

The original study scripts consume active_mnq.pkl. The public preparation script writes both Parquet and pickle formats from the same active-contract construction.
