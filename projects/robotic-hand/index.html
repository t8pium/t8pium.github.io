TeleHand Robotics / Computer vision + mechatronics

Natural hand motion, translated into robotic movement.

TeleHand Robotics is a computer-vision-driven robotic hand project focused on turning natural human finger movement into real-time physical actuation. The working prototype combines hand tracking, motion mapping, Arduino control and tendon-driven mechanics.

Working prototype Vision → control → physical motion
Markerless input No motion-capture glove required
Next build planned 3D-printed hand + Raspberry Pi vision
The project started as a low-cost proof of concept built from accessible materials. The next iteration focuses on a more rigid 3D-printed structure, cleaner actuation and a path toward networked teleoperation.

What it solves

Many robotic systems are controlled through joysticks, specialised controllers or motion-capture hardware. TeleHand explores a more natural interface: move your hand in front of a normal camera and let the robot mirror the intent.

The core engineering challenge is not only recognising a gesture, but reliably converting vision data into smooth, bounded, repeatable physical movement.

Current prototype

The first working version validates the complete control chain: hand movement is captured by a camera, computer vision extracts landmarks, software maps the motion into servo commands, and an Arduino drives five tendon-actuated fingers.

Development

Built

Mark I — proof of concept

The first version prioritised learning speed over appearance. Cardboard, simple guides, micro servos and string tendons made it possible to validate the mechanics without waiting for a refined enclosure.

  • Rapid physical iteration
  • Five independently actuated fingers
  • Arduino serial control
  • Computer-vision input
In development

Next generation — 3D-printed architecture

The next build keeps the same human-to-robot control idea while replacing the temporary structure with a stronger articulated hand, cleaner tendon paths and a dedicated forearm actuator module.

  • 3D-printed articulated hand
  • Forearm-mounted metal-gear servos
  • Raspberry Pi 5 vision processing
  • PCA9685 servo driver + dedicated power

Next-gen system

The planned upgrade moves vision processing onboard, improves mechanical repeatability and separates servo power/control more cleanly. This creates a better foundation for calibration, networking, force sensing and future teleoperation experiments.

Where it could go

Operate a dexterous end-effector from a separate location using natural hand movement.

Assistive robotics

Explore more intuitive control interfaces for robotic and rehabilitation systems.

Hazardous environments

Keep the operator physically separated from tasks that are unsafe or difficult to access.

Healthcare research

Long-term research direction in tele-assistance, haptics and remotely controlled robotic systems.

TeleHand is currently an engineering prototype, not a medical device or surgical system. Healthcare applications are a long-term research direction rather than a claim about the current hardware.

Engineering lessons

The project made the difference between software demos and physical systems obvious. Friction, servo jitter, tendon tension, angle limits, wiring, power delivery and structural stiffness can all dominate performance even when the computer-vision code works.

That is why the next version focuses as much on mechanical and electrical architecture as on the tracking algorithm itself.
