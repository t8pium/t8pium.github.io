Portfolio CMS / Project Gallery Manager

A Windows desktop app that turns structured project inputs into finished portfolio gallery cards and full case-study pages without manually editing HTML.

Status
Prototype
Focus
Static portfolio automation
Source
GitHub repo

Problem

Adding projects to a static HTML portfolio is repetitive: copy markup, change titles, copy cover assets, create a detail page, and avoid breaking the layout. The more projects get added, the more the portfolio needs a simple content-management layer.

Build

  • Built a local Python desktop app with customtkinter.
  • Added fields for project title, slug, category, status, description, tech stack, GitHub link, cover image, and case-study sections.
  • Created a generator module that copies cover images, writes project detail pages, and inserts or replaces project gallery cards.
  • Added a Windows batch build script that packages the app into an EXE with PyInstaller.

What it shows

This project shows practical internal tooling: desktop UI design, file automation, static-site generation, HTML templating, and building a workflow around a real portfolio instead of manually editing the same markup every time.

Next version
