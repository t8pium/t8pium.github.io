What it does

This project started as a simple automatic keyboard presser and evolved into a fuller desktop automation panel with a clickable keyboard, physical key detection, combo pressing, and macro replay.

Keyboard automation

  • Clickable virtual keyboard for selecting keys.
  • Supports combinations like Ctrl + A, Ctrl + V, Shift + Tab, and Alt + F4.
  • Detects left/right Ctrl, Shift, Alt, Win, arrows, function keys, letters, numbers, and symbols.
  • Press repeatedly mode uses a configurable interval.
  • Hold down mode hides the interval because it is not needed.

Macro recorder

  • Records mouse movement, clicks, and scroll.
  • Records keyboard input.
  • Can record mouse + keyboard together.
  • Replays a recording once or continuously.
  • Supports instant looping or a custom wait time between loops.

Controls

  • F6 starts the selected action.
  • F8 stops everything and releases held inputs.
  • F9 toggles recording.
  • F10 stops recording.

Boundary

The app sends real keyboard and mouse input to the active window. It is meant for local workflows where the user is allowed to automate input, with an easy stop hotkey kept available.
