Automatic Keyboard Presser

A Windows desktop utility for building key combos, repeating or holding them, and recording keyboard plus mouse macros through a clear visual interface.

Problem

I wanted a simple local tool where someone could choose a key combo visually, set whether it repeats or holds, and control it with predictable global hotkeys instead of editing scripts every time.

Interface

  • Virtual keyboard for clicking keys into a combo.
  • Physical key capture for adding real key input.
  • Clear combo and undo-last-key controls.
  • Repeat and hold-down modes with interval control.
  • Status indicators for selected combo and readiness.

Macro recorder

  • Record mouse, keyboard, or both.
  • Play, stop, and clear recorded events.
  • Optional continuous loop playback.
  • Simple hotkey-driven controls for starting and stopping.

What it shows

The project combines state handling, keyboard layout logic, macro event recording, repeat timing, global controls, and a UI that makes the workflow obvious.
